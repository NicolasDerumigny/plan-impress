Plan Impress adds a "Plan" menu to LibreOffice Impress.

* Insert Plan Slides puts one overview slide in front of the first section and
  one plan slide at the top of every section. Each plan slide lists all the
  sections of the presentation; only the current section is drawn in the text
  colour, the others use the muted colour.
* Remove Plan Slides takes them all out again.
* Insert Section Titles writes the name of each slide's section above its
  heading. Running it again updates those boxes instead of adding duplicates,
  and Remove Section Titles takes them away again.
* Settings... picks the muted colour, the highlight colour, the heading of the
  generated slides, the master slide they are based on, and what a section name
  looks like where there is nothing to copy.
* Toggle Debug Log writes a trace of every command to a log file.

Plan slides are named "PlanImpress:...", which is how the extension recognises
its own output: running the command again regenerates them instead of adding
duplicates. Settings are stored per user profile, so they survive updates.
